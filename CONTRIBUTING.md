# Contributing

Thanks for your interest in WG Map Backporter Studio.

This repository is currently **source-available rather than open source**, and the project is being kept under a restrictive licence while its long-term product direction is decided.

## Issues and feedback

Bug reports, compatibility reports, conversion failures, feature ideas, block-mapping suggestions, and reproducible test cases are welcome through GitHub Issues.

When reporting a conversion problem, please avoid uploading copyrighted maps, modpacks, or mod JARs unless you have permission to redistribute them. Prefer logs, minimal reproduction files, block names, Minecraft versions, and screenshots where possible.

## Code contributions

Code pull requests are **not accepted by default at this stage**. Please open an issue before preparing a code contribution.

This avoids unclear copyright ownership while the project is still deciding its future contribution and commercial/licensing model. If external code contributions are opened later, the repository will add an explicit contributor agreement or contribution licence before accepting them.

Documentation corrections and small factual fixes may still be proposed through an issue first.

## Development discussion

Useful areas for discussion include:

- legacy and modern Anvil chunk formats,
- block-state conversion rules,
- visual block matching,
- Forge/Fabric/NeoForge mod asset analysis,
- CurseForge/Modrinth pack analysis,
- target-version adapters,
- safe handling of tile entities and modded registries,
- macOS and Windows packaging reliability.
