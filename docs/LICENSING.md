# Licensing model

WG Map Backporter Studio is currently published as a **source-available** project under the PolyForm Strict License 1.0.0.

The intent is to let people inspect the source and use official community builds for qualifying non-commercial purposes while preserving the project owner's ability to decide later whether to commercialise, dual-license, open-source, or otherwise change the licensing model for future releases.

## What the project licence is intended to prevent

The current licence does not grant permission for third parties to:

- repackage and redistribute the application,
- publish modified builds,
- create a competing/rebranded derivative from this source,
- commercially exploit the project without separate permission.

## GitHub public-repository behaviour

A public GitHub repository can still be viewed and forked using GitHub's platform functionality. Those platform rights do not automatically grant a broader software licence for modification or redistribution.

## Friends and community users

Official community builds may be downloaded and used for qualifying non-commercial purposes under the project licence. Users should obtain builds from the project's own GitHub Releases page rather than mirrors.

## Future licensing

The copyright holder may offer future releases under different terms, including commercial, dual, or open-source terms. A licence change for a future release does not automatically relicense earlier releases unless explicitly stated.

## Contributions

External code contributions are not accepted by default while the licensing model is being established. See [`../CONTRIBUTING.md`](../CONTRIBUTING.md).
